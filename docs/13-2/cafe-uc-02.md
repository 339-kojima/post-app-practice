#### UC-02: 商品を注文する

- **アクター**: 顧客
- **事前条件**: なし
- **基本フロー**:
  1. 顧客がメニューの中から注文する商品の種類を選ぶ
  2. システムが個数の選択画面と「かごに入れる」ボタンを表示する
  3. 顧客が「かごに入れる」ボタンを押す
  4. システムが注文の内訳と「支払いに進む」ボタン、「メニュー一覧に戻る」ボタンを表示する
  4. 顧客が「支払いに進む」ボタンを押す
  5. システムが注文の内訳と「注文を確定する」ボタンを押す
  6. システムが商品の合計金額、代金の出金元の銀行名と口座番号及び取引パスワードの入力欄、「支払い」ボタンを表示する
  7. 顧客が「支払い」ボタンを押す
  8. システムが注文完了画面と注文受付番号を表示する
- **代替フロー**:
  - 8a. もし顧客が注文受付番号表示画面を閉じてしまった場合：顧客がアプリを起動させた後、システムがメニュー一覧画面の上端部に注文受付番号を表示する
- **事後条件**: {終了後に成り立っていること}
- **受け入れ条件**:
  - [ ] メニューの個数が0の状態で「かごに入れる」ボタンを押すと、エラーメッセージが表示され、個数選択画面に留まる
  - [ ] 注文が完了すると、注文完了画面と注文受付番号が表示される
