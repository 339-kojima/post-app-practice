#### UC-06: 商品の引渡しを記録する

- **アクター**: 店員
- **事前条件**: 利用者からの注文が1件以上ある
- **基本フロー**:
  1. 店員が引渡し未完了の注文一覧画面を開く
  2. システムが注文受付番号と「引渡し済み」ボタンを表示する
  3. 店員が顧客に商品を渡し、「引渡し済み」ボタンを押す
  4. システムが注文の内訳と、「この注文を引渡し済みにしますか」というメッセージと「はい」ボタン、「いいえ」ボタンを表示する
  5. 店員が「はい」ボタンを押す
  6. システムが「引渡し済み」と記録し、引渡し未完了の注文一覧画面から消える
- **代替フロー**:
  - 5a. 「いいえ」ボタンを押す：引渡し未完了の注文一覧画面に戻る
- **事後条件**: {終了後に成り立っていること}
- **受け入れ条件**:
  - [ ] 引渡し未完了の注文一覧画面を開くと、注文受付番号と「引渡し済み」ボタンが表示される
  - [ ] 「引渡し済み」ボタンを押すと、注文の内訳と、「この注文を引渡し済みにしますか」というメッセージと「はい」ボタン、「いいえ」ボタンが表示される
- [ ] 「はい」ボタンを押すと、引渡し未完了の注文一覧画面から注文受付番号か消える
