画面項目定義

| 項目名 | 種類 | 必須 | 内容 |
|:---|:-----|:-----|:-----|
| 画面見だし | 表示 | - | 「メニュー」 |
| 注文の状況を見る | リンク | - | 押すと注文が店に届いているかを確認できる |
| フード | 表示 | - | 商品の種類を明示 |
| 商品名 | 表示 | - | 商品名を表示 |
| 説明 | 表示 | - | 商品について短文で説明 |
| 値段 | 表示 | - | 商品の値段を表示 |
| 個数 | 表示 | 必須 | 左右にある「-」ボタンと「+」ボタンで注文する個数を増減 |
| かごに入れるボタン | ボタン | - | ボタンを押すと注文確定画面に進む |
| 売切れ | 表示 | - | 売切れであることを明示 |
| 飲み物 | 表示 | - | 商品の種類を明示 |
