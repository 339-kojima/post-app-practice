画面一覧

| ID | 画面名 | 役割 | 主な利用者 |
|:---|:---|:---|:-----------|
| SC-01 | メニュー選択画面 | その日のドリンク・フード一覧を見せ、注文する商品と個数を選ぶ（最初に開く画面） | 顧客 |
| SC-02 | 注文確定画面 | 選んだ商品と個数、合計金額を確定させる | 顧客 |
| SC-03 | 支払い画面 | 外部の決済サービスに支払依頼をし、その結果を受け取る | 顧客 |
| SC-04 | 支払い完了画面 | 注文受付完了を知らせ、注文受付番号を表示する | 顧客 |
| SC-05 | 注文状況確認画面 | 注文が店側に届いているかの確認や注文取消をする | 顧客 |
| SC-06 | 注文一覧画面 | 商品引渡し前の注文を表示する（最初に開く画面） | 店員 |
| SC-07 | 注文引渡完了画面 | 注文受付番号の照会が終わった注文を「引渡済み」にし、その注文を注文一覧画面から削除する | 店員 |
