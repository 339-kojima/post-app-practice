画面項目定義

| 項目名 | 種類 |必須 | 内容 |
|:---|:-----|:-----|:-----|
| 画面見出し | 表示 | - | 「経費を申請する」 |
| 立替日 | 入力（1行） | 必須 | 経費を立替えた日。 |
| 金額 | 入力（1行） | 必須 | 立替えた金額。 |
| 費目 | 選択 | 必須 | 「交通費」「書籍代」「会議費」「その他」から一つ。 |
| 用途 | 入力（1行） | 必須 | 経費の使用用途。 |
| 差し戻しの理由 | 表示 | - | 差し戻された申請を修正するときだけ表示。 |
| 提出するボタン | ボタン | - | 押すと申請一覧画面へ移行。 |
| やめるボタン | ボタン | - | 押すと申請一覧画面へ移行。 |
